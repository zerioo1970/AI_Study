## 核心目标（已具体化）

基于**中国 A 股日 K 线数据**（可用近 20 年），判断**当日是否为上涨 / 下跌的趋势转折点**
（change point detection / regime shift detection）。

详细技术方案见 `docs/A股转折点检测方案.md`，涉及建模时必须先遵循该文档。

### 战略定位

- **优先攻"下跌转折点"（风险预警）**，而非收益预测。
  理由：T+1 下卖出信号可当日执行、买入被锁定至次日；下跌伴随波动率放大，特征更显著。
- 起步用**指数**（建议沪深300）而非个股。
- 决策时点先采用**方案 1：今日开盘前**（仅用 t-1 及之前完整日 K 线）；
  待流程无泄漏后再升级**方案 2**（baostock 分钟数据，真正盘中）。

### 决策时点（已明确，见 `docs/决策时点设计.md`）

| | 时点 | 当日可用信息 |
|---|---|---|
| **方案 1** | 9:25–9:30，以开盘价成交 | 仅：开盘价、集合竞价成交量、隔夜外部数据（美股/VIX/A50夜盘/商品/汇率） |
| **方案 2** | **建议 14:55**（14:57 后进入收盘集合竞价，不接受撤单） | 当日高/低/量已基本定型，价≈收盘价 |

方案 1 采用"开盘价代理法"：当日 收盘/最高/最低 一律用当日开盘价代替，历史日不变。
→ 因 `O=H=L=C`，**禁止**构造当日 K 线形态特征（振幅/实体/影线恒为 0，是无信息常量）；
改用**跳空幅度（今开/昨收−1）**、今开在昨日区间的位置、今开与均线关系、集合竞价量比。

方案 2 训练-推理一致性天然成立（历史完整日 K 线 ≈ 14:55 状态），无需代理；
但属**横截面选股排序**问题，后期可用 `lambdarank`，评估改用 IC / RankIC 与分档收益单调性。

## A 股专属铁律（写任何代码前必须确认）

0. 🚨🚨 **训练-推理一致性（最高优先级）**
   训练集中每一个样本日，**无一例外**，都必须按实盘那一刻的信息边界构造特征。
   反例：若只对"转折点样本"做开盘价代理，则转折点日振幅恒为 0、非转折点日振幅>0，
   模型只看振幅是否为 0 即可识别标签 → AUC 接近 1.0 而实盘无效。
   这是**标签通过特征分布反向泄漏**，不涉及未来价格，极难察觉。
   自检三法：① 断言 `O==H==L==C` ② **泄漏探针**（单用可疑特征组训练，AUC 应≈0.5）
   ③ 训练集与近期实盘特征分布对比。

1. 🚨 **盘中不可知今日收盘价 / 全天最高 / 全天最低 / 全天成交量** —— 用到即未来函数。
   方案 1 下所有特征构造完毕后统一 `shift(1)`，并写入断言自检。
2. 🚨 **前复权价格本身是未来函数**（随未来分红送股变化）→ 必须用**后复权**或复权因子当时点还原。
3. **必须使用真实交易日历**，禁止按自然日 `resample`。
4. **涨跌停**（主板 ±10%、ST ±5%、创业板/科创板 ±20%）时买不进卖不出 → 回测须排除该时点成交假设。
5. **交易成本**往返约 0.1% 量级（佣金 + 卖出印花税 0.5‰ + 过户费）→ 所有评估必须扣除成本。
6. **时序验证须 purge + embargo**：标签用了未来 N 日数据，训练集末端必须剔除重叠 N 天并留隔离带。
7. **同一交易日的横截面样本必须落在同一折内**，禁止跨折。
8. 留出**最近 2–3 年为纯样本外**，只在全部工作完成后评估一次；必须做**分年度稳定性检验**。
9. 注意**制度变迁**（股改 / 2010 股指期货 / 2015 杠杆牛 / 2016 熔断 / 注册制 / ±20% 涨跌幅），
   早期规律可能失效；若模型仅早期有效、近年失效，**判定为失败**。
10. 注意**停牌数据空洞**、**幸存者偏差**（退市股票不可排除）。
11. **一字板涨跌停必须标记为不可执行**并在回测中排除。
12. **真实盘中快照无法事后补齐** → 应尽早建立每日自动下载归档脚本（日 K 线 + 分钟线）。

## 现实成功标准（不可放宽）

| 指标 | 及格线 |
|------|--------|
| AUC | 0.54 – 0.58；**> 0.65 优先怀疑泄漏** |
| 下跌转折精确率 | 55% – 60% |
| 确认延迟 | ≤ 2–3 日 |
| 概率分层单调性 | 必须单调（比 AUC 更可信） |
| 近 3 年表现 | 不明显衰减 |
| 扣成本后 | 优于买入并持有 |

必须对比基线：永远预测盘整、随机漫步、趋势延续、均线交叉、买入并持有。
**打不过基线即视为无价值。**

## 技术栈（只用这些）

- 数据处理：Pandas + NumPy，重点 `DatetimeIndex`、`resample`、`rolling`、`shift`、`diff`、`pct_change`
- 主力模型：LightGBM（`LGBMClassifier` / `LGBMRegressor`）+ `early_stopping`
  - 参数只聚焦 `num_leaves`、`learning_rate`、`n_estimators`、`min_child_samples`
- 验证：`TimeSeriesSplit` / walk-forward；**严禁** `train_test_split(shuffle=True)`
- 转折点检测：`ruptures`、CUSUM、HMM、`scipy.signal.argrelextrema`
- 解释性：SHAP
- 调参：Optuna
- 不平衡：`scale_pos_weight` / `is_unbalance` / 调整判定阈值
- 可视化与交付：Matplotlib，可选 Streamlit
- 部署形态：Python 训练并暴露 HTTP API，由既有 C#/.NET 系统调用

## 明确不引入

## 写代码时必须遵守

1. **禁止未来函数**：任何特征只能用当前时点及之前的数据；用 `.rolling()` 而非全局统计，注意 `shift(1)`
2. **禁止随机划分**：时间序列必须按时间切分
3. **必须给基线对比**：随机漫步（明天=今天）、趋势延续、移动平均交叉
4. **必须留最终测试集**：一段从未参与调参的数据，只在最后评估一次
5. **必须记录确认延迟**：信号发出时距真实转折过了几期
6. 代码需带中文注释，变量名清晰，优先可读性而非炫技

## 建模思路优先级

- A 回归：预测未来 N 期变化率（先验证流程）
- B 三分类：上升 / 下降 / 盘整（带阈值，推荐正式起点）
- C 转折点标注：`argrelextrema` 标历史拐点 → 极不平衡分类；**看精确率 / 召回率，不看准确率**

关键洞察：**转折信号藏在二阶变化里**（涨得越来越慢），斜率变化、动量衰减、
波动率突变比原始值更重要。

## 期望管理

转折点检测达到 60% 精确率、提前 2–3 期给信号即非常有价值。
号称 90% 准的基本是数据泄漏，必须主动排查。
模型定位为**报警器 / 辅助信号**，与学习者业务经验结合，而非全自动决策者。
