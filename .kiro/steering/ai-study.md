## 核心目标（已具体化）

基于**中国 A 股日 K 线数据**（可用近 20 年），判断**当日是否为上涨 / 下跌的趋势转折点**
（change point detection / regime shift detection）。

详细技术方案见 `docs/A股转折点检测方案.md`，涉及建模时必须先遵循该文档。

### 战略定位

- **优先攻"下跌转折点"（风险预警）**，而非收益预测。
  理由：T+1 下卖出信号可当日执行、买入被锁定至次日；下跌伴随波动率放大，特征更显著。
- 起步用**指数**（建议沪深300）而非个股。
- 决策时点先采用**方案 1：今日开盘前**（仅用 t-1 及之前完整日 K 线）；
  待流程无泄漏后再升级**方案 2**（baostock 分钟数据，真正盘中）。

### 决策时点（已明确，见 `docs/决策时点设计.md`）

| | 时点 | 当日可用信息 |
|---|---|---|
| **方案 1** | 9:25–9:30，以开盘价成交 | 仅：开盘价、集合竞价成交量、隔夜外部数据（美股/VIX/A50夜盘/商品/汇率） |
| **方案 2** | **建议 14:55**（14:57 后进入收盘集合竞价，不接受撤单） | 当日高/低/量已基本定型，价≈收盘价 |

方案 1 采用"开盘价代理法"：当日 收盘/最高/最低 一律用当日开盘价代替，历史日不变。
→ 因 `O=H=L=C`，**禁止**构造当日 K 线形态特征（振幅/实体/影线恒为 0，是无信息常量）；
改用**跳空幅度（今开/昨收−1）**、今开在昨日区间的位置、今开与均线关系、集合竞价量比。

方案 2 训练-推理一致性天然成立（历史完整日 K 线 ≈ 14:55 状态），无需代理；
但属**横截面选股排序**问题，后期可用 `lambdarank`，评估改用 IC / RankIC 与分档收益单调性。

## A 股专属铁律（写任何代码前必须确认）

0. 🚨🚨 **训练-推理一致性（最高优先级）**
   训练集中每一个样本日，**无一例外**，都必须按实盘那一刻的信息边界构造特征。
   反例：若只对"转折点样本"做开盘价代理，则转折点日振幅恒为 0、非转折点日振幅>0，
   模型只看振幅是否为 0 即可识别标签 → AUC 接近 1.0 而实盘无效。
   这是**标签通过特征分布反向泄漏**，不涉及未来价格，极难察觉。
   自检三法：① 断言 `O==H==L==C` ② **泄漏探针**（单用可疑特征组训练，AUC 应≈0.5）
   ③ 训练集与近期实盘特征分布对比。

1. 🚨 **盘中不可知今日收盘价 / 全天最高 / 全天最低 / 全天成交量** —— 用到即未来函数。
   方案 1 下所有特征构造完毕后统一 `shift(1)`，并写入断言自检。
2. 🚨 **前复权价格本身是未来函数**（随未来分红送股变化）→ 必须用**后复权**或复权因子当时点还原。
3. **必须使用真实交易日历**，禁止按自然日 `resample`。
4. **涨跌停**（主板 ±10%、ST ±5%、创业板/科创板 ±20%）时买不进卖不出 → 回测须排除该时点成交假设。
5. **交易成本**往返约 0.1% 量级（佣金 + 卖出印花税 0.5‰ + 过户费）→ 所有评估必须扣除成本。
6. **时序验证须 purge + embargo**：标签用了未来 N 日数据，训练集末端必须剔除重叠 N 天并留隔离带。
7. **同一交易日的横截面样本必须落在同一折内**，禁止跨折。
8. 留出**最近 2–3 年为纯样本外**，只在全部工作完成后评估一次；必须做**分年度稳定性检验**。
9. 注意**制度变迁**（股改 / 2010 股指期货 / 2015 杠杆牛 / 2016 熔断 / 注册制 / ±20% 涨跌幅），
   早期规律可能失效；若模型仅早期有效、近年失效，**判定为失败**。
10. 注意**停牌数据空洞**、**幸存者偏差**（退市股票不可排除）。
11. **一字板涨跌停必须标记为不可执行**并在回测中排除。
12. **真实盘中快照无法事后补齐** → 应尽早建立每日自动下载归档脚本（日 K 线 + 分钟线）。

**归一化的正确处理（v1.10 定论，已修正 v1.9）**

⚠️ **重要前提：用户的归一化从未用于 LightGBM，只用于河流图与 3D 图**
（目的是防止各指标叠加时薄厚不均）。因此**不要再指控其造成建模泄漏** ——
树模型不受量纲影响，用户这一点做得对。

仍需改为 `x.rolling(250).rank(pct=True)`，但**理由不是防泄漏，而是**：

1. ⭐ **Min-Max 根本达不到用户"薄厚均匀"的目的**（这是最有说服力的论证）：
   Min-Max 只对齐最大最小值、不对齐实际分布。
   例：成交量比（平时 0.5~2、偶尔暴增到 20）→ min-max 后 95% 时间挤在 0.03~0.10（薄如纸）；
   RSI（有界 0~100、实际 20~80）→ min-max 后 0.20~0.80（很厚）。
   **两者厚度仍差近 10 倍，正是用户想消除的问题。**
2. ⭐⭐ **百分位排名的结果天生均匀分布在 [0,1]**（排名变换的数学性质）
   → 任何指标的条带动态范围完全一致，**这才是真正的薄厚均匀**。
3. 对异常值免疫（一个尖峰不会毁掉全图）。
4. 语义清晰（"处于过去一年的 X% 分位"）。
5. 顺带满足训练-推理一致性：**用户要用图做当下判断**
   （开盘前 5 分钟 / 收盘前 2 分钟），而实盘只能用截至当日的 min/max，
   与历史图的全 20 年 min/max **不是同一尺度** →
   同一原始值在不同时点画出的厚度不同，"图案→结论"的映射不稳定。
   这是第 0 号铁律作用在**眼睛**上而非模型上。

**用户已自行提出滚动窗口方案（v1.11）—— 框架正确，须予肯定**
用户提议用过去约 30 个交易日的 min/max 作边界并随日期递进，并说
"也许不准，但规则却对大家都是一样的"。
→ 这正是**训练-推理一致性（第 0 号铁律）**，用户独立说出了它，应明确肯定。
→ 要点：**归一化的目的不是"求真值"而是"提供稳定参照系"，故一致 = 准。**

仍需调整两处（不是否定框架）：
1. **窗口内公式 min-max → rank**。决定性理由：窗口内若有巨大尖峰，
   min-max 的分母被撑大会**把其他所有天压到接近 0**（一个异常值污染整个窗口）；
   而 rank 中尖峰只占一个名次，其他天排名不受影响。
   （诚实说明：今天恰为窗口最高值时两者都给 1.0，这是窗口方法共性；区别在中间区域。）
2. **窗口 30 → 250**。30 天的三个问题：① 趋势中频繁**饱和**（连续多日 1.00，
   看不出"鼓到最大后开始瘪"）；② 极值滚出窗口造成**人工跳变**（不是数据变了是窗口变了）；
   ③ ⭐ **破坏"极端性"** —— "平静一月后的温和波动"与"暴跌前的历史级异动"都显示 1.00。

**⭐⭐ 推荐多窗口并用**（周期维度的另一种形态）：
`pct_60` / `pct_250` / `pct_750`。
`pct_60=1.0` 但 `pct_750=0.5` → 仅近期偏高，是噪音；两者皆 1.0 → 真异动。
**`pct_60 − pct_750` 本身即优质特征。** 可视化上画短/长窗口并排（小倍数图）。

**河流图实现**（与双向堆叠合并）：
```python
pct = x.rolling(250).rank(pct=True)   # 0~1 均匀
dev = pct - 0.5                       # dev>0 向上堆(红)；dev<0 向下堆(蓝)；零线固定
```
→ 厚度均匀 + 方向天然分离 + 零线固定 + 无泄漏，一次满足四个需求。

**仍然成立的核心泄漏**：1000+ → 150 的筛选在全部 20 年上完成（见下）。本轮修正不影响该结论。

**筛选环节的两个额外问题（v1.9 新增）**
- **多重比较**：1000 多个候选中，即使全是纯噪音，5% 水平下**约 50 个也会"看起来显著"**。
  从 1000 选 150（15%），其中必然混入运气选手。
- **LightGBM 重要性在共线特征上极不稳定**：1000+ 指标全派生自同一份 OHLCV，
  同族互相抢功劳、**换 random_state 排名就变**、重要性 ≠ 预测力。
  更稳健：permutation importance、多 seed 平均排名、族级重要性。
- 两个立即可做的检验：① 换 3 个 seed 看前 150 名重合度；② 2006–15 vs 2016–25 排名稳定性。

**⭐ 关于「贴合度」的正确表述（v1.9 修正，重要）**
- ✅ **"衡量指标与目标的贴合度"完全正当且必须做** —— 这就是特征选择，标准 ML 步骤。
  **不要否定这件事**（此前表述曾让用户误解，已修正）。
- ❌ 真正的问题是"**用同一份数据既做选择、又做验证**"。
  选择阶段可以充分看答案；验证必须用未参与选择的数据。
- 类比：可以看着答案研究一道题总结思路（合理）；但不能拿同一道题证明"我掌握了"。
- 三段划分：2006–2015 选 / 2016–2021 调 / **2022–2025 冻结只看一次**。
- ⭐ **框架要点：这不是加限制，而是给成果发证书。**
  若那 150 个指标真捕捉到稳定规律，用 2006–2015 选出的在 2022–2025 上应仍有效 ——
  **该检验不会毁掉成果，而是证明成果**；若通不过说明成果本就不存在，
  **早知道远好过晚知道，晚知道的代价是真金白银**。

### Z 轴排序：推荐两级排序（v1.8）

```
主序：按相关性聚类族分组     ← 相近指标聚在一起
族内：按周期从短到长排列     ← 使"波沿 Z 传播"具物理意义
```

相似度度量优先级：**斯皮尔曼秩相关**（金融厚尾，优于 Pearson）→
**带时滞的互相关**（传播的本质就是时滞，须记录最优时滞作为"传播速度"特征）→ DTW（后期）。

"把相近曲线移在一起"的标准答案：
`scipy.cluster.hierarchy.linkage(..., optimal_ordering=True)` + `leaves_list`。
距离用 `1 - corr.abs()`（完全负相关的两指标其实是同一信息）。
⚠️ **相关矩阵只能用训练期数据计算。**

不推荐按波动率排序（会产生同义反复）。

评估结论（详见 `docs/指标热力图与图像化方法.md`）：
- ⭐ **指标生成逻辑与 `[通道 × 时间]` 的矩阵组织方式是正确且有价值的资产，必须保留**
- ⚠️ **两处疑似泄漏需排查**：① 归一化是否用了全历史范围（必须改滚动/扩展窗口）
  ② 150 个指标是否在全部数据上筛选（**特征选择偏差**，留出测试集也发现不了）
- ⚠️ 150 指标全部派生自同一份 OHLCV，**高度共线**，真实独立维度可能仅 10–20 个
  → 需相关性层次聚类降到 20–30 族；热力图行序也必须按聚类排列才能看出结构
- ❌ **不建议直接训练 CNN**（约 145 个正样本必然过拟合）；
  若要用卷积思想应用 **ROCKET / MiniRocket / MultiRocket**，
  但注意其性能随通道数极多而下降，需先聚类降维
- ✅ **热力图应重新定位为「诊断仪表盘」**：四轨道对照面板（热力图 + 价格 + 真实转折点 + 模型概率）；
  并强烈推荐 **SHAP 热力图**（同布局，颜色 = SHAP 值）
- ⚠️ 提醒 apophenia 风险：「看起来有用」需通过**盲测**验证（遮住后续走势判断 50 次并统计）

> 原则：**需要修的是流程（归一化方式、筛选时机），不是思路。**
> 讨论其可视化或指标时，先肯定已有资产价值，再指出流程问题。

### ⭐ 「气泡块」直觉的量化（后续建模的核心特征）

设第 t 日第 g 族因果 z-score 为 z（按方向统一，正=看涨）：

| 视觉 | 公式 | 含义 |
|---|---|---|
| 气泡大小/颜色 | `S = mean(z)` | 族强度 |
| 气泡整齐度 | `C = abs(mean(sign(z)))` | 族一致性 |
| 气泡参差 | `D = std(z)` | 族内分歧 |
| 红蓝对抗 | `S_看涨 − S_看跌` | 跨族分化 |
| **鼓到最大后瘪** | `ΔC = C(t) − C(t−5)` | ⭐ 一致性的二阶变化 |

转折点假设：**一致性 C 处于历史高分位 且 ΔC 开始转负**。
这与项目核心洞察（转折信号藏在二阶变化里）完全一致，是其在多指标一致性维度的版本。

金融理论支撑：Breadth（广度）、Dispersion（离散度）、Divergence（背离）——
趋势中段指标高度一致、末端出现分歧，故"一致性本身的变化"即转折信号。

> 用户方法论（先人眼验证 → 再量化 → 再自动化）属 **human-in-the-loop 特征发现**，
> 是正确且专业的做法，应予肯定并维持该顺序。
> 但须明确：人眼负责发现与确认规律，**5000 只股票 2 分钟内判断必须靠量化**。

### ⭐ 周期维度是真正的第三维（v1.6 新增，重要）

用户早期曾设想 3D 可视化，已正确放弃。但需注意：

- ❌ **不要建议 3D 立体可视化**（遮挡、透视失真、深度感知精度差、不可复现、无法批量扫描）
- 根本原因：`[指标 × 时间]` **本质二维**，3D 第三轴只是把颜色换成高度，**未增加信息维度**
- ⭐ 但若 150 个指标含大量"同一指标的不同周期"（RSI-6/12/24、MA偏离-5/10/20/60 等），
  则真实结构为 `[指标类型 × 周期参数 × 时间]` —— **"时间尺度"才是真正独立的第三维**

**周期维度对转折点判断的价值**（术语：信号期限结构 / 多尺度一致性）：

| 现象 | 含义 |
|---|---|
| **短周期已转、长周期未转** | ⭐ 早期转折信号（最有价值） |
| 全周期同时转向 | 强烈确认但很可能已晚 |
| 短周期摇摆、长周期稳定 | 噪音 |

补充量化特征：`尺度分化 = S_短 − S_长`、`传导时滞`、`短周期领先度 = C_短 − C_长`。

**合并后的完整转折假设**：
```
早期下跌转折信号 = 短周期族一致性已转负
                 且 长周期族一致性仍为正但 ΔC < 0
                 且 尺度分化处于历史极端分位
```

**可视化**：按周期分面的**小倍数图（small multiples）**，并排多张 2D 气泡矩阵。
通用经验：想加第三个维度时，答案通常是"多画几张 2D 图"，而非"画一张 3D 图"。

**语言分工**：探索/试错/画图用 **Python**（Matplotlib 生态成熟）；
最终生产系统与既有系统对接用 **C#**。不要建议用 C# 做探索性可视化。

### 用户 3D 设想的准确形态（v1.7 校正，勿再误解）

用户的 3D 设计是**曲面图 / 瀑布图**：X = 时间（一日一格）、
**Y = 指标数值（高度，已归一化）**、Z = 150 个指标依次排列。

- 正名：**3D 曲面图 / 瀑布图（waterfall plot，信号处理与振动分析的经典图形）**；
  其 2D 版本是**山脊图（ridgeline / joyplot）**
- 有力先例：**振动分析与声学领域已从 3D 瀑布图转向 2D 彩色谱图做自动化分析**，
  3D 仅留作演示 —— 与用户判断一致
- ⚠️ **校正前述"3D 没有增加信息"的说法**：信息量相同，
  但**"高度"通道比"颜色"读得更准**；只是 150 条曲线的**遮挡（且随视角变化）**完全抵消该优势
- ⚠️ 用户观察"转折日波动大的靠近 Z 轴零轴"**可能是排序产物（同义反复）** ——
  需 Z 轴随机重排后重画验证
- ⭐⭐ 用户观察"**波沿 Z 轴从远到近来回传播**"是金子，**但前提是 Z 轴按周期长短排序** ——
  此时即"信号从短周期向长周期传导"，与传导时滞/信号期限结构是同一件事；
  "波刚从短周期开始往长周期推"= **早期转折信号**
- 追加可量化特征：相邻 Z 层的**互相关最优时滞**（传播速度）、
  **时滞符号**（方向，短→长正常）、**互相关峰值**（传播强度）

## 技术栈（只用这些）

- 数据处理：Pandas + NumPy，重点 `DatetimeIndex`、`resample`、`rolling`、`shift`、`diff`、`pct_change`

  - 参数只聚焦 `num_leaves`、`learning_rate`、`n_estimators`、`min_child_samples`
- 验证：`TimeSeriesSplit` / walk-forward；**严禁** `train_test_split(shuffle=True)`

- 解释性：SHAP
- 调参：Optuna

- 可视化与交付：Matplotlib，可选 Streamlit
- 部署形态：Python 训练并暴露 HTTP API，由既有 C#/.NET 系统调用

## 写代码时必须遵守

1. **禁止未来函数**：任何特征只能用当前时点及之前的数据；用 `.rolling()` 而非全局统计，注意 `shift(1)`
2. **禁止随机划分**：时间序列必须按时间切分
3. **必须给基线对比**：随机漫步（明天=今天）、趋势延续、移动平均交叉
4. **必须留最终测试集**：一段从未参与调参的数据，只在最后评估一次
5. **必须记录确认延迟**：信号发出时距真实转折过了几期
6. 代码需带中文注释，变量名清晰，优先可读性而非炫技

## 建模思路优先级

- A 回归：预测未来 N 期变化率（先验证流程）
- B 三分类：上升 / 下降 / 盘整（带阈值，推荐正式起点）
- C 转折点标注：`argrelextrema` 标历史拐点 → 极不平衡分类；**看精确率 / 召回率，不看准确率**

关键洞察：**转折信号藏在二阶变化里**（涨得越来越慢），斜率变化、动量衰减、
波动率突变比原始值更重要。
