## 三条最重要的认知

1. **日 K 线无法支撑真正的"盘中"判断** —— 盘中不知今日收盘价/全天高低量，用了即未来函数。
   先做「今日开盘前决策」的方案 1，再升级到分钟数据的方案 2。
2. **优先攻"下跌转折点"** —— T+1 制度下卖出可当日执行；风险预警比收益预测更务实。
3. **AUC > 0.65 请优先怀疑数据泄漏** —— 金融场景 0.54–0.58 即属可用。
