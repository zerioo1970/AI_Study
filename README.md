## 五条最重要的认知

1. **训练-推理必须一致** —— 训练时构造特征的方式，必须与实盘那一刻的信息边界完全相同。
   若只对部分样本做特殊处理，标签会通过特征分布反向泄漏（AUC 接近 1.0 而实盘无效）。
2. **日 K 线无法支撑真正的"盘中"判断** —— 盘中不知今日收盘价/全天高低量，用了即未来函数。
   方案 1（9:25 开盘价代理）→ 方案 2（14:55 尾盘，信息完整）。
3. **优先攻"下跌转折点"** —— T+1 下卖出可当日执行；风险预警比收益预测更务实。
4. **AUC > 0.65 请优先怀疑数据泄漏** —— 金融场景 0.54–0.58 即属可用。
5. **瓶颈几乎不可能是"模型不够强"** —— 修正一个泄漏或加一个好特征，收益远大于换模型。
