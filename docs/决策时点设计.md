# 决策时点设计 —— 方案 1 与方案 2

> 本文档定义"在哪个时刻做判断、此刻究竟知道什么信息",这是整个项目**最容易出错、也最决定成败**的环节。

## 方案 1：开盘前决策（开盘价代理法）

### 1.1 设计

```
9:15–9:25  集合竞价
9:25       开盘价确定并公布  ← 此刻信息冻结
9:25–9:30  模型计算并决策
9:30       以开盘价成交
```

特征构造方式：**将当日的 收盘价 / 最高价 / 最低价 全部用「当日开盘价」代替**，
历史各日保持完整日 K 线不变。

### 1.2 评价：思路正确，且有三个天然优势

| 优势 | 说明 |
|------|------|
| ✅ 无未来函数 | 9:25 开盘价确实已知，合法可用 |
| ✅ **几乎无滑点** | 9:30 的成交价就是开盘价，你用来算特征的价格 = 你的成交价 |
| ✅ 契合 T+1 | 卖出/减仓信号可在开盘直接执行（持仓非当日买入） |

> 「用来计算的价格 = 能成交的价格」这一点极其难得。很多策略的回测幻觉就死在这里
> （用收盘价算信号、假设按收盘价成交，实际根本来不及）。方案 1 天然规避了这个问题。

---

### 1.3 🚨 必须修正的致命细节：训练-推理一致性

你的原话是「训练时，也是以**每个转折点**的开盘价，当作当日的收盘价、最高价、最低价」。

这句话有两种解读，**一种正确，一种会彻底毁掉模型**：

#### ❌ 错误解读：只对「转折点样本」做替换

若转折点那天用 `O=H=L=C`，而非转折点那天用完整日 K 线，则：

| 样本 | 当日振幅 | 当日实体 |
|------|---------|---------|
| 转折点日 | **恒为 0** | **恒为 0** |
| 非转折点日 | > 0 | > 0 |

> 🚨 模型只要看一眼「今天振幅是不是 0」，就能 **100% 识别标签**。
> AUC 会接近 1.0，你会以为发现了圣杯 —— 实盘上一分钱都赚不到。
>
> 这是**标签通过特征分布反向泄漏**，比普通未来函数更隐蔽，因为它不涉及任何未来价格。

#### ✅ 正确解读：每一天都是决策日，一律同样处理

**铁律：训练集中的每一个样本日，无一例外，都必须用与实盘完全相同的方式构造。**

```
对第 t 日的样本：
  特征 = f( 第 t-1 日及之前的完整日 K 线,
            第 t 日开盘价,
            第 t 日集合竞价成交量,
            隔夜外部信息 )
  标签 = g( 第 t 日之后 N 日的走势 )   ← 只有标签可以用未来
```

**训练时特征的分布，必须与实盘 9:25 时刻的分布完全一致。** 这是不可妥协的。

#### 三个自检手段（务必写进代码）

1. **断言检查**：所有样本满足 `today_high == today_low == today_close == today_open`
2. **泄漏探针**：只用「当日 bar 派生特征」训练一个模型，**AUC 应 ≈ 0.5**。
   若显著高于 0.5 → 一定有泄漏，立即排查
3. **分布对比**：训练集特征分布 vs 最近 N 个交易日实盘特征分布，应无系统性偏移

### 1.4 三个可以立刻提升效果的改进

#### 改进 1：不要构造「当日 K 线形态」特征（它们全是常量）

因为 `O=H=L=C`，当日的振幅、实体、上下影线**恒等于 0**，是无信息的常量。
计算它们纯属浪费，还可能引入上述泄漏风险。

**改为这些真正有信息量的特征**：

| 特征 | 含义 |
|------|------|
| **跳空幅度** = 今开 / 昨收 − 1 | ⭐ 最核心。隔夜情绪的直接度量 |
| 今开在昨日区间中的位置 | 今开 vs 昨高 / 昨低，判断是否跳出昨日范围 |
| 今开 vs 各均线 | 今开 / MA5、MA20、MA60，是否跌破关键均线 |
| 跳空幅度 / 近20日波动率 | 标准化后的跳空强度（可跨时期比较） |
| 连续跳空方向 | 连续几日同向跳空 |

#### 改进 2：集合竞价成交量 —— 被浪费的金矿 ⭐

9:25 时你**还知道一个关键信息：集合竞价的成交量 / 成交额**。这几乎总是被忽略。

| 特征 | 解读 |
|------|------|
| 竞价量 / 近20日均量 | 情绪强度 |
| 竞价量 / 近20日首分钟均量 | 更可比的口径 |
| 竞价量突增 + 大幅低开 | 恐慌性抛售 → 可能是下跌加速，也可能是恐慌底 |
| 竞价量萎缩 + 平开 | 观望情绪，趋势可能延续 |

> 这是方案 1 中**最有价值的额外信息源**，与价格信息互补。强烈建议纳入。

#### 改进 3：隔夜外部信息（9:25 前全部已知，完全合法）

| 类别 | 具体 |
|------|------|
| 美股 | 前夜标普500 / 纳指涨跌幅、VIX 及其变化 |
| **富时中国A50期货夜盘** | ⭐ 直接反映外资对 A 股的预期，信息量最高 |
| 商品 | 原油、铜、黄金隔夜涨跌 |
| 汇率 | 美元指数、离岸人民币 CNH |
| 债市 | 10 年期国债收益率变化 |

> 港股当日行情不可用（9:30 同时开盘），但**恒指期货夜盘**可用。

#### 改进 4：涨跌停与一字板必须标记

集合竞价即涨停（一字板）→ **根本买不进**。
必须在样本中标记 `是否可执行`，回测时排除，否则收益虚高。

## 方案 2：收盘前 2 分钟决策（全市场扫描）

### 2.1 设计

约 14:58 对全市场股票做一次判断，选出合适标的。
理由：临近收盘价格已趋于稳定。

### 2.2 ⭐ 你可能没意识到的巨大优势：训练-推理一致性天然成立

这是方案 2 **远优于方案 1** 的地方：

| | 训练时用的数据 | 推理时的真实状态 | 是否需要构造代理 |
|---|---|---|---|
| **方案 1（9:25）** | 历史完整日 K 线 | 当日**只知开盘价** | ⚠️ **必须构造代理，损失大量信息** |
| **方案 2（14:58）** | 历史完整日 K 线 | 当日高/低/量已基本定型，价 ≈ 收盘价 | ✅ **几乎不需要，误差极小** |

> **结论：方案 2 可以直接用历史日 K 线训练，不需要任何人为代理。**
> 特征信息完整（真实的振幅、实体、影线、全天量、量价关系全部可用），
> 这比方案 1 那个"当日 O=H=L=C"的退化 bar 强太多了。
>
> 这也解释了为什么方案 1 的天花板必然低于方案 2 —— **方案 1 丢掉了整个交易日的信息**。

### 2.3 三个必须处理的约束

#### 约束 1：收盘集合竞价 —— 决策窗口比你想的更窄

沪深两市尾盘设有**收盘集合竞价**阶段（约 14:57–15:00），该阶段**不接受撤单**。

- 14:57 之后**无法**按连续竞价方式成交
- 若在 14:58 才决策，只能通过收盘集合竞价成交 → **成交价 = 当日收盘价**
- ✅ 好消息：你算特征用的价格 ≈ 你的成交价，滑点极小
- ⚠️ 坏消息：若想在连续竞价中成交，决策必须在 **14:55 前**完成

**建议**：把决策时点定为 **14:55**，用 14:55 的快照构造特征（与收盘价差异通常很小）。

> ⚠️ 交易时间与竞价规则以交易所最新公告为准，实施前请自行核实。

#### 约束 2：T+1 —— 尾盘买入风险最大

14:58 买入 → **次日才能卖**，承担整夜隔夜风险，且次日开盘跳空**完全无法规避**。

> 这再次印证了**优先做卖出/减仓信号**的战略。尾盘卖出可立即执行且规避隔夜风险，
> 尾盘买入则是把风险敞口最大化。

#### 约束 3：工程约束 —— 2 分钟扫描 5000 只

| 要点 | 做法 |
|------|------|
| 历史特征 | **盘前预计算并缓存**，盘中只更新当日 bar |
| 全市场快照 | 用批量行情接口（一次请求取多只），非逐只轮询 |
| 特征计算 | 全程向量化；数据量大时考虑 Polars 替代 Pandas |
| 超时兜底 | **若未在窗口内完成，宁可不交易**，不可用残缺数据决策 |
| 接口稳定性 | 免费源有频率限制与封 IP 风险，需重试与多源切换 |

### 2.4 注意：方案 2 是一个**不同类型**的问题

| | 问题类型 | 方法 | 评估指标 |
|---|---|---|---|
| 方案 1 | 单一标的**择时** | 分类 / 回归 | AUC、精确率、策略收益 |
| 方案 2 | 全市场**横截面选股排序** | 分类 → 后期可用 LightGBM `lambdarank` | **IC / RankIC**、分档收益单调性 |

- 方案 2 需按日做横截面标准化（否则不同日期不可比）
- **同一交易日的全部股票样本必须落在同一折内**，否则跨折泄漏
- 个股引入新问题：停牌、ST、退市（幸存者偏差）、流动性不足

## 3. 数据积累的紧迫性 ⚠️

> **实时快照数据无法事后补齐。**

| 需求 | 能否回补 | 应对 |
|------|---------|------|
| 历史日 K 线 | ✅ 可回补 | akshare 随时取 |
| 历史分钟线（5/15/30/60分钟） | ✅ 可回补 | **baostock 有历史分钟线** |
| 历史集合竞价量 | ⚠️ 部分接口有，需核实 | 尽早验证并归档 |
| 真实盘中快照（如 14:55 全市场） | ❌ **无法回补** | 需从现在开始每日录制 |

**建议现在就做的一件小事**：写一个每日自动下载并归档的脚本（日 K 线 + 分钟线）。
即使还没开始建模，**数据先攒起来**。一年后你会感谢现在的自己。

## 4. 两个方案的定位（路线不变）

| | 定位 |
|---|---|
| **方案 1** | **学习与验证方法论的最佳载体**：数据小、逻辑清晰、无滑点、可解释性强。<br>用它把「无泄漏流程」彻底走通。 |
| **方案 2** | **最终实用形态**：信息完整、无需代理、可做全市场选股。 |

**顺序：先方案 1（打地基）→ 再方案 2（要效果）。**
但**分钟数据从现在就开始下载积累**，不要等。

---

## 5. 两个方案共同的铁律清单

1. 训练特征分布必须与推理时刻完全一致（**训练-推理一致性**）
2. 所有特征构造完毕后统一 `shift`，并写断言自检
3. 只用后复权（或复权因子还原），禁用前复权
4. 标记并排除涨跌停等不可执行时点
5. 扣除往返约 0.1% 交易成本后再评估
6. 时序验证须 purge + embargo；同日样本同折
7. 留最近 2–3 年纯样本外，只测一次
8. 泄漏探针测试：单用可疑特征组训练，AUC 应 ≈ 0.5
