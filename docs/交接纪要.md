## 2. 目标

**主目标**：A 股日 K 线 → 判断当日是否为**下跌转折点**（风险预警）。

**两个决策时点**

|---|---|---|---|

| **方案 2** | **建议 14:55**（14:57 后进入收盘集合竞价） | 当日高/低/量已基本定型 | 后做（最终形态） |

## 3. 已确定的结论（不必重新讨论）

**技术栈**：Pandas + LightGBM + `TimeSeriesSplit`(purge/embargo) + 特征工程 + SHAP +
ruptures / ZigZag；数据用 akshare（日线）、baostock（分钟线）；调参 Optuna。

**明确排除**：深度学习（CNN/RNN/LSTM/Transformer）、数学公式推导、LLM 微调、
NLP/图像/语音、复杂 ARIMA 理论、Polars（等方案 2 再说）、直接训 CNN。

**战略**：**只攻下跌方向**。理由：T+1 下卖出信号可当日执行；规避损失确定性更高；
下跌伴随波动率放大、特征更显著。

**成功标准**（不可放宽）：AUC 0.54–0.58 即可用，**>0.65 优先怀疑泄漏**；
下跌转折精确率 55–60% 即有价值；确认延迟 ≤2–3 日；概率分层需单调；
近 3 年不衰减；扣成本（往返约 0.1%）后优于买入持有。
必须打过基线：永远预测盘整 / 随机漫步 / 趋势延续 / 均线交叉 / 买入持有。

**核心洞察（贯穿全部方案）**：
> **转折信号藏在"二阶变化"里 —— 不是"在涨"，而是"涨得越来越慢"。**
> 三个层面同时指向它：① 价格斜率衰减 ② 指标一致性 ΔC 转负 ③ 短周期先塌、长周期跟松。

## 4. 铁律（写任何代码前必看）

0. 🚨🚨 **训练-推理一致性（最高优先级）** —— 训练时构造特征的方式必须与实盘那一刻的
   信息边界完全相同。若只对部分样本特殊处理，标签会通过特征分布反向泄漏。
   自检：断言 + **泄漏探针**（单用可疑特征训练，AUC 应≈0.5）+ 训练/实盘分布对比。
1. 盘中不可知今日收盘价/全天高低量；特征算完统一 `shift(1)`。
2. **前复权价格本身是未来函数** → 必须用后复权或复权因子还原。
3. 必须用真实交易日历，禁止按自然日 resample。
4. 涨跌停（含一字板）标记为不可执行，回测须排除。
5. 时序验证须 **purge + embargo**；同一交易日的横截面样本必须同折。
6. 禁止 `train_test_split(shuffle=True)`。
7. 留最近 2–3 年为纯样本外，全部做完只测一次；必须做分年度稳定性检验。
8. 注意制度变迁（股改/2010股指期货/2015杠杆牛/2016熔断/注册制/±20%涨跌幅）；
   **若模型仅早期有效、近年失效 → 判定失败**。
9. 归一化目的是**提供稳定参照系**，不是求真值 —— **一致 = 准**。
10. **瓶颈几乎不可能是"模型不够强"** —— 修一个泄漏 > 换十个模型。切勿建议堆模型。

## 6. 已定的可视化方案（四图分工）

| 图 | 看什么 | 可容纳 | 定位 |
|---|---|---|---|
| **气泡矩阵**（大小=强度，颜色=方向） | 哪些族在动、强不强、齐不齐 | 降到 20–30 族 | 主力扫描图 |
| **双向堆叠河流图**（看涨向上/看跌向下，零线固定） | 总合力对抗 | 不限 | 合力对抗图 |
| **山脊图**（ridgeline） | 波形形状 + 波沿 Z 传播 | 20–40 | 形态细看图 |
| 3D 曲面图 | 直观讲解 | ≤10 | **仅演示，不用于分析** |

**Z 轴排序（推荐两级）**：主序按相关性聚类族（`linkage(..., optimal_ordering=True)`，
距离用 `1-corr.abs()`，**只用训练期数据**）；族内按周期从短到长。
**禁止手工排序**（会不自觉按已知答案排 → 后见之明，且不可复现）。

**「气泡块」直觉的量化**（视觉 → 特征的桥梁）：
`S=mean(z)` 族强度 / `C=abs(mean(sign(z)))` 族一致性 / `D=std(z)` 族内分歧 /
`S_涨−S_跌` 跨族分化 / **`ΔC=C(t)−C(t−5)` 一致性的二阶变化**。
外加周期维度：`尺度分化=S_短−S_长`、传导时滞、`短周期领先度=C_短−C_长`。

**完整的早期转折假设**：
```
短周期族一致性已转负
且 长周期族一致性仍为正但 ΔC < 0     ← 长周期开始松动
且 尺度分化处于历史极端分位
```

## 12. 与学习者互动的注意事项

- **他的直觉一直很准**（二阶变化、共激活、周期传导、规则一致性都是他自己想到的），
  **出问题的都是执行细节**。讨论时应先肯定判断，再指出细节。
- 他会**认真反驳**。已有两次反驳促使修正结论（贴合度表述、归一化用途）。
  **反驳有理时应明确承认并撤回**，不要含糊。
- 方法论上他是对的：**先人眼验证假设 → 再量化 → 再自动化**
  （human-in-the-loop 特征发现），应予维持。
- ⚠️ 需持续提醒的风险：**apophenia（人眼在噪音中找模式）** ——
  "看起来挺有用"必须靠**盲测**验证。
- 期望管理：转折点检测 60% 精确率 + 提前 2–3 期已很有价值；
  **模型定位是"报警器"而非"决策者"**，与他的业务经验结合。
- ⚠️ 本项目为技术学习与研究，**不构成投资建议**；
  不得建议用真实资金验证未经充分样本外检验的模型。
